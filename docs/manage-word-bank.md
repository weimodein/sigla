# Manage Word Bank

The Manage Word Bank module allows administrators to control and maintain all the words available in the system. Through this module, the admin can add, edit, delete, and manage gesture data for each word.

When adding a new word, the admin uses the **Add Word** button and fills in the word itself, a short description, the number of hands required (one or two), and the gesture type, which can be either **static** (a still hand position) or **motion** (a moving gesture). Words added manually do not have gesture samples at first, so the admin must upload samples before the word can be activated. The admin can also edit existing words to update their spelling, description, number of hands, or gesture type. If a word is no longer needed, the admin can delete it, which also removes all its related gesture samples.

The admin can upload gesture samples directly to any word, especially for words that were manually added. These samples are uploaded as a batch of images, and the system automatically processes each image using the **MediaPipe** hand detection framework to extract hand landmark coordinates, the same way it handles samples submitted by users. All samples uploaded by the admin are automatically marked as **approved** and counted toward the required number of samples. For a word to be activated, it must meet the minimum sample requirement: at least **100 approved samples** for static gestures and at least **150 approved sequences** for motion gestures.

For motion gestures, the admin can generate a demonstration video using the approved samples. This video is created by the system's machine learning component and shows how the gesture is performed. The admin can generate a video at any time, even before reaching the required number of samples, to check if the gesture looks correct. Videos can be generated for a single sequence or for multiple selected sequences at once. After generating, the admin can preview the video and adjust its playback speed. Once the word has met the required number of approved samples, the admin can click **Set as Word Bank Video** to publish the video to the mobile app. This action activates the word, and it will appear in the mobile application after it reloads. For static gestures, no video is needed. Once the required number of samples is met, the admin can activate the word directly using the **Approve** button.

The module also allows the admin to review gesture samples submitted by users through the Suggest a Word feature. By opening the gallery of a word, the admin can see all submitted samples grouped by the user who submitted them, along with the status of each sample, which can be pending, approved, or rejected. When reviewing, the admin checks each sample against the following quality criteria: the hand gesture must be clearly visible, the gesture formation must be correct, the hand must be fully visible and not cut off, the camera framing must be appropriate, and the image must not contain unrelated or inappropriate content.

The admin can approve or reject samples at different levels. Individual samples can be approved or rejected one by one. All samples from a specific user can be approved or rejected at once. All pending samples for the entire word can also be approved or rejected at the same time, regardless of who submitted them. Each group of samples submitted by a user counts as one **submission**, and the admin can approve or reject an entire submission using the **Approve Submission** or **Reject Submission** buttons.

After a submission is reviewed, the system automatically sends a notification to the user. If only some of the samples are approved, the user is told how many were accepted and how many more they are still allowed to submit. If all samples are approved, the user is notified that their entire contribution has been accepted. If all samples are rejected, the user is advised to review the terms and conditions before submitting again. If a submission contains inappropriate or irrelevant content, the word will not be added to the system and the user will be notified.

Once enough samples have been collected and no more are needed, the admin can **lock** the word to stop users from submitting additional samples. Locking a word does not affect samples that are still waiting for review — those can still be reviewed normally. The admin can also **unlock** the word later if more samples are needed.

On the user side, a user is allowed to resubmit samples for a word if their previous submission was rejected, as long as the admin has already completed the review. However, once a user's submission has been approved, they can no longer add more samples to that same word. If the word is locked or the user has already reached their allowed number of samples, the system will show a message that no more submissions can be made for that word.

To keep the system appropriate and safe, the admin can issue a **warning** to a user who submits inappropriate or offensive words, uploads gesture images with inappropriate or irrelevant content, or violates the system's terms and conditions. Warnings can be issued directly during sample review in the gallery or through the **Manage Users** module. If a user receives **two warnings**, their account is automatically suspended for **30 days**. After 30 days, the account is automatically reactivated. If the user violates the rules again after reactivation, the admin may permanently delete the account from the system.
